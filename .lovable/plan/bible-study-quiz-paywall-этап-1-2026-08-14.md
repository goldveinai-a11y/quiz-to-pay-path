# Bible Study Quiz + Paywall (этап 1)

Собираем воронку: 22-шаговый квиз → экран анализа → отчёт + пейволл → чекаут-модалка (пока витрина, без реального списания). Структура и ощущение — как в референсе Stylix, тематика и визуал — Bible study tool.

## Что будет сделано

### 1. Дизайн-система
Mobile-first, спокойная «книжная» палитра (тёплый пергамент, глубокий чернильно-синий, акцент — приглушённое золото), серифные заголовки + гротеск в тексте. Все цвета — токены в `src/styles.css`, никаких хардкодов.

### 2. Движок квиза (конфиг, не хардкод)
Один компонент-движок читает массив шагов. Типы шагов:
- `single` — один выбор, авто-переход
- `multi` — мультивыбор + кнопка Continue
- `cards` — карточки с иконкой/картинкой (шаги 9, 10)
- `statement` — «That's me / Not really» (шаг 7)
- `interstitial` — экран-передышка со статистикой и источником (шаги 8, 12)
- `slider` — 1–10 (шаг 17)
- `demo` — разбор греческого слова ἠγάπησεν (шаг 18)
- `input` — имя (19), email + чекбокс рассылки, не предвыбран (20)
- `analysis` — 7 сек, круговой прогресс, 4 сменяющиеся строки + микро-опрос «Shorter / Deeper» на 4-й секунде (21)

Сверху: прогресс-бар с секциями, кнопка «назад». Ответы живут в сторе и в localStorage, чтобы не терялись при перезагрузке. UTM и `?mode=` из URL сохраняются и прокидываются дальше.

### 3. Контент
Беру ваш драфт как основу, дорабатываю формулировки под конверсию: короче, от первого лица, без церковного жаргона. Шаги 3, 9, 10, 14/15 влияют на текст отчёта (традиция → перевод и стартовая книга, темы → путь, дни/время → темп).

### 4. Отчёт (перед пейволлом)
Персональный блок: «Your 30-Day Plan», стартовая книга, темп X дней/нед по 7 минут, график «понимание сегодня (из слайдера) → через 30 дней», список тем из шага 10.

### 5. Пейволл (по вашим скринам)
Длинный скролл: баннер промокода с таймером → выбор тарифов (триал по низкой цене → подписка, средний выделен как популярный) → «What's inside» → блоки до/после (адаптация: «стих непонятен» → «стих с разбором и контекстом») → мокапы продукта → 100% money-back guarantee → отзывы → FAQ → липкая кнопка CTA.

### 6. Чекаут-модалка
Total today, поле email (подставляется из шага 20), кнопки Apple Pay / Google Pay / карта — визуально как в референсе. На этом этапе кнопки ведут на экран-заглушку «Payment coming soon»; реальную оплату и аккаунты подключаем следующим шагом.

## Технические детали
- TanStack Start, роуты: `/` → редирект на `/quiz`, `/quiz` (движок), `/result` (отчёт + пейволл), `/checkout` (модалка поверх result).
- Конфиг шагов: `src/lib/quiz/steps.ts`; логика отчёта: `src/lib/quiz/plan.ts`; состояние: `src/lib/quiz/store.ts` (localStorage).
- Head-метаданные на каждый роут; квиз-шаги — `noindex`.
- Бэкенда пока нет — всё на клиенте. Lovable Cloud (база, аккаунты, сохранение ответов, подписки) включаем на следующем этапе вместе с оплатой.

## Следующие этапы (не сейчас)
Аккаунты и логин → реальная оплата (триал → подписка) → сам продукт: 30-дневный план, чтение, заметки, разбор оригинала, прогресс.
