# Главный экран (лендинг) перед квизом

Сейчас `/` просто редиректит на `/quiz` — входного экрана нет. Делаю нормальный лендинг в стиле PLAINLY (пергамент, чернила, Fraunces, гравюрный арт), по структуре Inspoy, но короче: 7 экранов вместо 15.

## Структура страницы `/`

1. **Хедер** — логотип Plainly по центру, тонкая линия снизу.
2. **Герой** — крупный заголовок Fraunces («Понимай Библию, а не просто читай её»), подзаголовок, арт-иллюстрация (`art-hero`) в скруглённой карточке с наложенной «карточкой результата»: стих + разобранное слово + бейджи (как «Light Summer / Best colors» у Inspoy, но про разбор стиха). Тёмная кнопка **Start** на всю ширину.
3. **Соц-доказательство** — ряд аватар-кружков (инициалы, без стоковых лиц) + «40 000+ человек читают Библию каждый день с Plainly».
4. **Почему Plainly** — 3 блока «мокап телефона + заголовок + одна строка описания» (переиспользую существующий `PhoneMock`): ежедневное чтение за 7 минут, разбор слов оригинала, контекст и перекрёстные ссылки.
5. **Отзывы** — 2–3 карточки со звёздами, текстом и именем (инициалы в кружке).
6. **FAQ** — 4 вопроса аккордеоном с круглой кнопкой «+» справа.
7. **Финальный CTA + футер** — заголовок «Начни сегодня», кнопка Start, тёмный футер с логотипом, ссылками Privacy / Terms и копирайтом.

Обе кнопки Start ведут на `/quiz` с сохранением всех UTM-параметров из URL.

## Технические детали

- Переписываю `src/routes/index.tsx`: убираю `beforeLoad` redirect, рендерю лендинг; свой `head()` с title/description/og.
- Новые компоненты в `src/components/landing/`: `Hero`, `FeatureRow`, `Reviews`, `Faq`, `SiteFooter`. Аккордеон — на существующих UI-примитивах.
- Только токены из `src/styles.css` (ink, parchment, terra, teal, gold), никаких хардкод-цветов; арт — из `src/lib/quiz/art.ts`.
- Переход на квиз через `<Link to="/quiz" search={...}>`, чтобы не терять рекламные метки.
- Проверю страницу в браузере на мобильной ширине со скриншотами.
