# Продукт после оплаты: что берём из микролернинга и bibleplan.app

## Честный разбор рекомендаций

Половина советов Gemini у нас уже сделана: стрик, прогресс-бар сессии, шаги «один экран — одна мысль», тап/свайп по краям, ежедневное письмо, заметки, словарь слов, «Ask anything». Из остального беру три вещи и осознанно отбрасываю остальное.

**Берём (дёшево, реально снижает рефанды):**
1. Нижняя навигация из 3 вкладок (как на bibleplan.app) — разгружает бесконечный скролл дашборда.
2. Микро-квиз: 1 вопрос в конце сессии с мгновенным объяснением — превращает пассивное чтение в участие.
3. Экран успеха: «день закрыт», стрик +1 с плавной сменой цифры, кнопка «поделиться цитатой» (ShareCard уже есть).

**Отбрасываем — и почему:**
- XP/очки/уровни: вторая валюта поверх стрика, много кода, ноль пользы для 30-дневного плана.
- Коллекционные стикеры/карточки-награды: требует дизайна десятков ассетов, «детская» эстетика противоречит тону.
- Вертикальный свайп как в TikTok: у нас текст Писания, а не лента; горизонтальные шаги уже работают.
- Push-уведомления: web-push на iOS требует установки PWA, поддержка дорогая — письмо покрывает ту же роль.
- Видео/аудио-выжимки: производство контента на 90 сессий, отдельный бюджет.
- Drag-n-drop, «верно/неверно» свайпом, конфетти, Lottie: анимации ради анимаций, риск раздражения.
- Streak Freeze за очки: заморозки в базе уже есть, отдельная экономика не нужна.

## Что делаем

### 1. Нижняя навигация и разгрузка дашборда
Три вкладки на всех экранах продукта: **Сегодня · План · Заметки**, плюс иконка настроек в шапке.
- **Сегодня** — только карточка дня, стрик и кнопка «Continue». Ничего лишнего.
- **План** — список 30 дней и переключение книг.
- **Заметки** — существующий экран.
- **Настройки** (отдельный экран) — доступ/биллинг, отмена, апгрейд, ежедневное письмо, выход, юридические ссылки.
Сейчас всё это — один длинный скролл; после изменения первый экран влезает без прокрутки.

### 2. Микро-квиз в конце сессии
Между шагом «вопрос» и «завершение» добавляется один вопрос с 3 вариантами:
- выбор варианта → мягкая подсветка (зелёная/приглушённая), сразу короткое объяснение почему;
- ошибка не блокирует — можно продолжить в любом случае, никакого наказания;
- если для дня вопроса нет — шаг просто не показывается.
Контент: по одному вопросу на каждую из 90 сессий, авторский, на основе уже импортированного текста и контекста. Разовая генерация в сид-файл, без обращений к ИИ в рантайме.

### 3. Экран завершения дня
После «Mark today done» вместо мгновенного возврата — короткий экран: «День 7 закрыт», цифра стрика плавно перекатывается, строка «осталось 23 дня», кнопки «Поделиться» и «На главную». Один спокойный переход, без конфетти.

## Технические детали
- Роуты: `/plan` (сегодня), `/plan/all` (список дней), `/notes`, `/settings` под `_authenticated`; общий layout с нижним таб-баром в `src/routes/_authenticated/route.tsx`, контент внутри `<Outlet />`.
- Таб-бар — `position: sticky` внизу, три крупные цели ≥44px, скрывается на экране сессии `/plan/$day` (режим чтения без отвлечений).
- Квиз: новая таблица `session_quiz` (book_slug, day_number, question, options jsonb, correct_index, explanation) с публичным SELECT и GRANT для anon/authenticated; данные заливаются миграцией с литеральными INSERT. `buildSessionDay` отдаёт блок `quiz` в `SessionDay`; ответ пользователя хранится локально в состоянии шага, в БД не пишем.
- Экран успеха — новый шаг `celebrate` в существующем массиве шагов сессии, без нового роута.
- Анимация цифры стрика — CSS translate/opacity 250ms, без библиотек.

## Чего не трогаем
Воронка, пейволл, оплата, письма, авторизация, содержимое сессий — без изменений.
